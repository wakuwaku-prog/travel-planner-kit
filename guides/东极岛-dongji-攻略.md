# 东极岛 3 天 2 晚穷游攻略（2026.10.29–31 周四至周六 · 单人 · 上海出发）

> 去看中国最东边的海。三天两晚只做两座岛：**东福山**（日出 + 环岛徒步）与**庙子湖**（灯塔 + 《后会无期》）。
> 穷游档人均约 800–1200 元，全程没有景区门票，花销主要是船票和住宿。
> ⚠️ 深秋东北季风期，**大风停航是第一风险**——先读「四条交通硬约束」和「停航预案」，再看玩法。
> 文中班次/票价均为规划估算或近期网络信息，**出发前以官方购票页与『东极海运』公告为准**。

## 行程总览

| 天 | 日期 | 主题 | 线路 | 关键卡点 |
|---|---|---|---|---|
| D1 | 10.29 周四 | 车船联运日 + 东福山村落日落 | 上海南浦大桥 → 沈家湾 → 庙子湖 → 东福山 | 08:20 发车 / 10:30 开船 |
| D2 | 10.30 周五 | 东福山日出 + 环岛徒步 → 傍晚转场庙子湖 | 东福山环岛 → 岛际船 → 庙子湖灯塔 | 06:01 日出 / 东福山→庙子湖班船 |
| D3 | 10.31 周六 | 庙子湖精华环线 → 返程（沈家湾线本季最后一天） | 庙子湖环线 → 沈家湾 → 上海 | 13:40 开船（错过无船） |

## 四条交通硬约束（先看这个）

1. **沈家湾线每天只有一班。** 南浦大桥旅游集散中心 **08:20** 大巴发车（约 2h，经东海大桥）→ 沈家湾 **10:30** 开船 → 庙子湖约 13:00 → 换乘后东福山约 14:00–14:30。**大巴和船都只有这一班，错过即当天到不了。**
2. **营运期 5/1–10/31，10/31 是本季最后一天。** 返程就是 10/31 的 13:40 船（庙子湖 → 沈家湾约 16:10 → 大巴回沪约 18:30）。**11/1 起沈家湾线停运**——别想着"玩累了明天再走"。
3. **两张票的放票节奏不一样，都要抢。** 去程：提前 7 天（**10/22 起**）在『舟山交通』/『嵊泗客运』小程序买；返程：提前 1 天（**10/30 早 7:00 前后**）在『东极海运』小程序买。10/31 是周六 + 本季末班，返程票尤其抢手。
4. **岛际船是行程的瓶颈。** 庙子湖 → 东福山：去程**在船上现金补票**（+30 元，备好零钱）；东福山 → 庙子湖：只能到**东福山候船室现场买**（最早一班约 8:45，淡季 ≤3 班，另有傍晚 17:2x 经青浜的班次）。D2 何时离开东福山由当天班次决定，**上岛就问民宿老板**。

## 路线 A（主线）+ 路线 B（备选）+ 停航预案

### 路线 A：上海 → 沈家湾 → 东极（本攻略主线）

南浦大桥旅游集散中心上车（07:50 集合换票）→ 大巴约 2h → 沈家湾码头 → 10:30 船 → 约 13:00 到庙子湖 → 同码头换乘 → 14:00–14:30 到东福山。

- 票价（发改批复）：下舱 130 / 卧铺 220 / 中舱 200 / 上舱 260 / 包厢 380；上海大巴段另计（约 110/程估算，以购票页为准）。
- 优点：一条龙省心，直达东福山；缺点：每天一班、受大风影响大、季末停运。

### 路线 B：上海 → 宁波 → 沈家门·半升洞 → 东极（备选 / 停航缓冲）

上海 → 宁波站（高铁）→ 宁波南站大巴约 2h（59–70 元）→ 普陀客运中心 → 打车 10–15 分钟 → 半升洞码头 → 船约 2h → 庙子湖。

- 半升洞 → 东极日常两班：**8:05 / 14:20**（节假日加开）；票价 下 100 / 中 130 / 上 150 / 贵宾 260。
- 购票：去程『智游海星』、回程『东极海运』。**半升洞线是全年航线**，不受"10/31 季末停运"影响。
- 注意：从半升洞到庙子湖后，去东福山还要再补岛际票；若赶 14:20 那班，要算好宁波 → 半升洞的耗时（高铁 2h + 大巴 2h + 打车 ≈ 6h 起）。

### 停航预案（大风是常态，先想好再做）

出发前 1 天 + 当天早上查『东极海运』公众号/小程序公告确认开航。

- **10/29 去程停航**：① 首选顺延 10/30 出发（返程仍是 10/31，压缩成"D2 环岛 + D3 庙子湖"仍能玩）；② 若沈家湾线持续停航 → 改走路线 B（半升洞，前提是宁波方向天气允许）；③ 最坏改期重订，民宿订可免费取消的。
- **10/31 返程停航**：① 待航，岛上续住（淡季好谈价，约 140/晚）；② 通航后优先走"东极 → 半升洞"线（全年航线）→ 宁波 → 上海；③ 若持续停航，做好多住 1–2 晚的准备（预算 +150–300）。
- 停航退改：官方渠道购票一般可退/改签，以购票页公告为准。

## 逐日要点

### D1（10.29 周四）车船联运日 + 东福山村落日落

- **07:00** 出发去南浦大桥旅游集散中心（地铁 4 号线南浦大桥站附近）；**07:50** 集合换票，**08:20** 大巴发车（经东海大桥，约 2h）。
- **10:00 前后** 到沈家湾码头，取票、安检（**开航前 30 分钟到码头**）。
- **10:30 开船**。上船后可补觉；**船快到庙子湖时留意广播**——去东福山的在船上现金补票（+30）。
- **13:00 前后** 到庙子湖，同码头换乘（10–40 分钟）→ **14:00–14:30 到东福山码头**。订了能接行李的民宿，下船直接交给老板。
- **16:30–18:00** 村落-海岸线散步：灯塔方向、石屋、海崖机位；**日落 17:04–17:06**（NOAA 估算）。
- **18:15** 晚餐：民宿餐食 / 云南风味海鲜餐厅。
- 提示：晕船药提前 30 分钟吃；岛上夜里极黑，走夜路带手电。

### D2（10.30 周五）东福山日出 + 全环岛 → 傍晚转场庙子湖

- **05:20** 起床 → 摸黑走到**第一缕曙光观测点**（约 10–15 分钟）；**06:01–06:02 日出**（中国大陆最早的日出之一）。
- **06:40 前** 回民宿早餐；预收行李（**9 点退房是惯例**，先和老板说好寄存）。
- **07:40 出发环岛（顺时针）**：大树湾石屋群 → 藏兵洞 → **象鼻峰**（精华悬崖段，拉铁链、慢走；体力/时间不够可在象鼻峰后折返）→ 白云宫 → 水泥公路回村/码头。全程 **7.2–10 km、4–6 h**；**带水 1.5–2 L**，中途仅石屋群有小卖部。
- **13:00-14:00** 回码头：先到**候船室买/确认 东福山 → 庙子湖 船票**（最早约 8:45 班，实际班次早上问民宿）。
- **15:00 前后** 上船 → 约 15:40 到庙子湖（若当天只剩傍晚 17:2x 经青浜班 → 灯塔挪到 D3 清晨，环岛不用赶）。
- 入住庙子湖 → **16:30–17:40** 红白灯塔（东海第一哨）晚照 → **日落约 17:06**。
- **18:00** 晚餐：东极海鲜面馆（海鲜面约 28 元）。

### D3（10.31 周六）庙子湖环线 → 返程

- **07:30** 出发庙子湖环线：财伯公雕像 → 《后会无期》取景地 → 东极亭 → 倒陡街。
- 全程步行约 **4.5–6 h**；想省力或赶时间坐**观光车 88 元**（环岛约 30 分钟，全部下客点约 1.5 h）。
- **11:40 前后** 回倒陡街一带午餐（海鲜面/炒米线）；**12:00** 回民宿退房取行李。
- **13:10** 到庙子湖码头；**13:40 开船**（硬卡点——本季最后一班，错过只能走半升洞线）。
- **16:10 前后** 到沈家湾 → 码头/船上买**回上海大巴票** → 约 2h → **18:30 前后到上海南浦大桥**。
- 提示：上山前把大水壶灌满；返程票 10/30 早 7:00 前后『东极海运』抢。

## 需要立刻做的事

1. **10/22 起抢去程票**：『舟山交通』或『嵊泗客运』小程序，买 10/29 南浦大桥 → 东福山 车船联运，设好闹钟（提前 7 天放票，分时段放出）。
2. **订住宿**（越早越好）：D1 住**东福山**、D2 住**庙子湖**，各 1 晚；订前问清 ① 能否接行李 ② D2 东福山→庙子湖当天班次。淡季可到了再谈价，但周末 + 末班船建议先订可免费取消的。
3. **10/30 早 7:00 抢返程票**：『东极海运』买 10/31 庙子湖 → 沈家湾。
4. **出发前 1 天 + 当天早上查公告**：『东极海运』公众号确认开航，套用「停航预案」。
5. **装备**：身份证、**现金 500–800**（船上补票只收现金）、防风外套/抓绒、运动鞋、晕船药、手电、充电宝、水壶（1.5–2 L 容量）。

## 必吃清单（穷游版）

海鲜面（东极海鲜面馆，约 28 元）· 海鲜炒米线（约 28 元）· 东福山民宿餐（渔家做法，约 50–80）· 云南风味海鲜餐厅（东福山，岛上口碑店）· 阿宝海鲜（仅路线 B：半升洞码头旁 300 m）· 码头小海鲜现买现做（问民宿加工费）。

穷游口诀：**山下海鲜面馆比山上大排档便宜近一半**（庙子湖）；东福山吃饭地方少，正餐优先靠民宿。

## 避坑提醒

- **后沙滩（庙子湖）约 80 元门票——避雷**，多篇笔记吐槽"最不值"，除非纯为出片。
- 岛上物价：水 5 / 可乐 7 / 泡面 10 元——自带水壶干粮，出发前在村里灌满。
- **东福山环岛顺时针**（省力且顺光）；象鼻峰段拉铁链，雨天/大风天谨慎，别逞强。
- 庙子湖环线：步行 4.5–6 h vs 观光车 88 元——穷游步行；赶船日只走"码头 → 财伯公 → 灯塔"短线即可。
- **现金 500–800**：船上补票、部分民宿和摊点收不了电子支付。
- 岛上信号时好时坏：本攻略配套 KML/GPX 可导入离线地图，网站每站可一键唤起高德导航。
- 10/31 周六 + 沈家湾线末班：**返程票是全程最紧张的一张票**，10/30 一早必抢。
- 海钓体验（观光钓）价格直接问民宿老板，别在码头找"黑中介"。
- 本攻略为规划估算，船班/票价/日出日落时间**出发前请再核对一次**（风向一变全线改）。
